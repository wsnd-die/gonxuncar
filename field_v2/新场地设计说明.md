# 《风车 · 四象》—— 2400 × 2400 竞赛场地设计方案

> 版本 v2.0 ｜ 基于现有 2400×2400 场地重做 ｜ 单位 mm
> 图纸：`new_field_layout.png`（布局）/ `new_field_flow.png`（任务流线）
> 生成脚本：`render_field.py`（改常量即可重出图）

---

## 0. 一句话说清

把「**一个中心 + 三条固定路线**」改成「**四角启停 + 四边可换工位 + 中央风车盘**」的
**旋转对称**场地：同一套路径程序转 90° 就能服务任意一个启停区，而工位的**角色每局随机**，
逼着队伍现场读任务牌，不能把路线写死。

---

## 1. 原图哪里不好玩

| 问题 | 后果 |
|---|---|
| 三个启停区到中心的距离几乎一样，路线唯一 | 战术趋同，比赛变成比谁跑得快、比谁不出错 |
| Ø800 中心圈是唯一瓶颈 | 两台车同时进就堵死，观感差、判罚争议多 |
| 功能写死：原料永远在北、二维码永远在东 | 队伍不「看」场地，赛前把 17 个点位背下来就够了（`g_waypoints[]` 现在正是这样用的） |
| 场地没有遮挡、没有陷阱 | 定位与路径规划退化成「直线 + 转向」，技术含量低 |

## 2. 三条设计主张

**① C4 旋转对称（四象）**
4 个启停区、4 个工位模块、4 根立柱、4 条对角通道，每隔 90° 完全一样。
好处：程序只需写一份，把坐标 (x,y) 旋转 k×90°、yaw 加 k×π/2 即可从任一角落发车；
同时也天然支持「四方同时入场」的对抗赛制。

**② 工位可换（角色随机）**
四个边缘工位是**同一套 580×300 接口的可插拔模块**：原料仓 / 粗加工台 / 成品暂存 / 任务牌。
赛前由裁判随机换位，并把**本局排列写进任务牌二维码**。
第一件事必须是「读牌」，读完才知道往哪边走 —— 路线的**拓扑**每局都变。

**③ 中央风车盘当节拍器**
Ø700 转盘上 4 个刀槽，**每放入一件自动转 90°**。
它把「放料—取料」的节拍强行拉成固定的 4 拍，双方必须在同一张盘上交错，
既制造了接触点，又给了落后方一个「抢拍」的机会。

## 5. 任务流程（每局 180 s，一场 3 局）

| # | 阶段 | 动作 | 时长预算 |
|---|---|---|---|
| 0 | 出发 | 从裁判指定的启停区出发（A/B/C/D 之一） | — |
| 1 | 侦察 | 到指定工位读任务牌二维码，得到**本局四工位排列**与色序 | 20 s |
| 2 | 取料 | 到原料仓，夹爪取 1 件，放入车载转盘 | 25 s |
| 3 | 粗加工 | 到粗加工台，把料压入夹具并**原地转 90°**（考试航向环） | 25 s |
| 4 | 入盘 | 到风车盘，放进当前空刀槽（北槽） | 15 s |
| 5 | 取成品 | 盘自动转 90°，从相邻刀槽取走成品 | 15 s |
| 6 | 交付 | 送到成品暂存区，回启停区 | 30 s |
| — | 循环 | 重复 2–6，共 3 件 | 3 × ~110 s |

计分建议：每件交付 30 分；首次读牌成功 +10；交付后**回到起点区并停稳** +15；
风车盘上每残留一件未取 −10（惩罚占坑）。

### 乘 90° 复用：从 B / C / D 出发

```c
/* 提案：未改动现有 g_waypoints[]；确认后再落地 */
static void Field_Rotate(float *x, float *y, float *yaw, uint8_t k)
{
    for (uint8_t i = 0; i < (k & 3u); ++i) {
        float nx = -*y;          /* 绕原点逆时针 90° */
        float ny =  *x;
        *x = nx;  *y = ny;
        *yaw += 1.5707963f;      /* 90° */
    }
    if (*yaw >  3.1415926f) { *yaw -= 6.2831853f; }
    if (*yaw < -3.1415926f) { *yaw += 6.2831853f; }
}
```

| 出发区 | k | 说明 |
|---|---|---|
| A（西南） | 0 | 上表直接用 |
| B（东南） | 3 | 顺时针 270°（= 逆时针 −90°，用 k=3 配合取负） |
| C（东北） | 2 | 转 180° |
| D（西北） | 1 | 逆时针 90° |

> 注意：旋转是**绕场地中心**还是**绕启停区原点**要统一。
> 上表的局部坐标原点就是 A 中心，所以绕原点转 k×90° 即可；B/C/D 的中心分别是
> 旋转后的 (0,0)，无需额外平移。

## 9. 平衡性与可调项

| 旋钮 | 现值 | 调大 → | 调小 → |
|---|---|---|---|
| 对角通道宽度 | 300 | 更容易超车 | 更容易堵 |
| 立柱位置半径 | 640 | 中心更空旷，走廊更堵 | 中心更挤 |
| 风车盘转动时间 | 1.5 s | 更考验节奏判断 | 更容易抢拍 |
| 工位距墙 | 150 | 车更容易卡在墙角 | 取放更困难 |
| 减速带位置 | r = 620 | 更早刹车 | 更晚刹车，更险 |

**风险点**

1. 工位换位若只是「口头指定」，队伍仍然可以硬编码 —— 建议**物理换位**（模块靠销定位，10 秒即可换）。
2. 车体对角线若大于 300，对角通道需加宽到 350（当前假设车体 ≤ 280）。
3. 中央踏盘抬高 20 会有台阶，需要 3 mm 倒角，否则麦轮上去会被卡。
